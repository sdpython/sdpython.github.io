.. _op_ai_onnx_BitwiseNot:

BitwiseNot
==========

- **Domain**: ``ai.onnx``
- **Since version**: 18

Returns the bitwise not of the input tensor element-wise.

**Inputs**

- **X** (*T*): Input tensor

**Outputs**

- **Y** (*T*): Output tensor

**Type Constraints**

- **T**: Constrain input/output to integer tensors.
  Allowed types: tensor(int16), tensor(int32), tensor(int64), tensor(int8), tensor(uint16), tensor(uint32), tensor(uint64), tensor(uint8).
