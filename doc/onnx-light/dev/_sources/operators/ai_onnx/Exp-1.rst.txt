Exp - version 1
===============

This page documents version **1** of operator **Exp**. See :doc:`Exp` for the latest version (since version 13).

- **Domain**: ``ai.onnx``
- **Since version**: 1

Calculates the exponential of the given input tensor, element-wise.

**Inputs**

- **input** (*T*): Input tensor

**Outputs**

- **output** (*T*): The exponential of the input tensor computed element-wise

**Attributes**

- **consumed_inputs** (*int[]*): legacy optimization attribute.

**Type Constraints**

- **T**: Constrain input and output types to float tensors.
  Allowed types: tensor(double), tensor(float), tensor(float16).
