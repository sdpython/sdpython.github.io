Gemm - version 6
================

This page documents version **6** of operator **Gemm**. See :doc:`Gemm` for the latest version (since version 13).

- **Domain**: ``ai.onnx``
- **Since version**: 6

General Matrix multiplication:
https://en.wikipedia.org/wiki/Basic_Linear_Algebra_Subprograms#Level_3
Compute Y = alpha * A * B + beta * C, where input tensor A has
dimension (M X K), input tensor B has dimension (K X N), input tensor C and
output tensor Y have dimension (M X N).
If attribute broadcast is non-zero, input tensor C will be broadcasted to match
the dimension requirement. A will be transposed before doing the computation
if attribute transA is non-zero, same for B and transB.

**Inputs**

- **A** (*T*): Input tensor A
- **B** (*T*): Input tensor B
- **C** (*T*): Input tensor C

**Outputs**

- **Y** (*T*): Output tensor.

**Attributes**

- **alpha** (*float*): Scalar multiplier for the product of input tensors A * B, the default value is 1.0.
- **beta** (*float*): Scalar multiplier for input tensor C, the default value is 1.0.
- **broadcast** (*int*): Whether C should be broadcasted
- **transA** (*int*): Whether A should be transposed
- **transB** (*int*): Whether B should be transposed

**Type Constraints**

- **T**: Constrain input and output types to float tensors.
  Allowed types: tensor(double), tensor(float), tensor(float16).
