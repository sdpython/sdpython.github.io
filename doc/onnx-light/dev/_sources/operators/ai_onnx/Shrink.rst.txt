Shrink
======

- **Domain**: ``ai.onnx``
- **Since version**: 9

Shrink takes one input data (Tensor ) and produces one Tensor output,
having same datatype and shape with input. It has two attributes, lambd and
bias. The formula of this operator is: If x   lambd, y = x - bias; Otherwise, y = 0.

**Inputs**

- **input** (*T*): The input data as Tensor.

**Outputs**

- **output** (*T*): The output.

**Attributes**

- **bias** (*float*): The bias value added to output. Default is 0.
- **lambd** (*float*): The lambd value for the Shrink formulation. Default is 0.5.

**Type Constraints**

- **T**: Constrain input to only numeric types.
  Allowed types: tensor(double), tensor(float), tensor(float16), tensor(int16), tensor(int32), tensor(int64), tensor(int8), tensor(uint16), tensor(uint32), tensor(uint64), tensor(uint8).
