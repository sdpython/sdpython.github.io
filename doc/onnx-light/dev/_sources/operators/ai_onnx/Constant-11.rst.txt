Constant - version 11
=====================

This page documents version **11** of operator **Constant**. See :doc:`Constant` for the latest version (since version 25).

- **Domain**: ``ai.onnx``
- **Since version**: 11

A constant tensor. Exactly one of the two attributes, either value or sparse_value,
must be specified.

**Outputs**

- **output** (*T*): Output tensor containing the same value of the provided tensor.

**Attributes**

- **sparse_value** (*sparse_tensor*): The value for the elements of the output tensor in sparse format.
- **value** (*tensor*): The value for the elements of the output tensor.

**Type Constraints**

- **T**: Constrain input and output types to all tensor types.
  Allowed types: tensor(bool), tensor(complex128), tensor(complex64), tensor(double), tensor(float), tensor(float16), tensor(int16), tensor(int32), tensor(int64), tensor(int8), tensor(string), tensor(uint16), tensor(uint32), tensor(uint64), tensor(uint8).
