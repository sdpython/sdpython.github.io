Upsample - version 7
====================

This page documents version **7** of operator **Upsample**. See :doc:`Upsample` for the latest version (since version 10).

- **Domain**: ``ai.onnx``
- **Since version**: 7

Upsample the input tensor.
Each dimension value of the output tensor is:
  output_dimension = floor(input_dimension * scale).

**Inputs**

- **X** (*T*): N-D tensor

**Outputs**

- **Y** (*T*): N-D tensor after resizing

**Attributes**

- **mode** (*string*): Two interpolation modes: nearest (default), and linear (including bilinear, trilinear, etc)
- **scales** (*float[]*): The scale array along each dimension. It takes value greater than or equal to 1. The number of elements of 'scales' should be the same as the rank of input 'X'.

**Type Constraints**

- **T**: Constrain input and output types to all tensor types.
  Allowed types: tensor(bool), tensor(complex128), tensor(complex64), tensor(double), tensor(float), tensor(float16), tensor(int16), tensor(int32), tensor(int64), tensor(int8), tensor(string), tensor(uint16), tensor(uint32), tensor(uint64), tensor(uint8).
