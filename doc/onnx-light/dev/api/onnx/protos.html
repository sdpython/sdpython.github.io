protos#

This page gives a high-level map of the ONNX protobuf message types exposed by onnx_light.onnx.

Core graph structures#

These classes represent the main model and graph topology.

onnx_light.onnx.Message(*args, **kwargs)

Message, base class for all onnx classes

onnx_light.onnx.ModelProto(*args, **kwargs)

ModelProto is a top-level file/container format for bundling a ML model and associating its computation graph with metadata.

onnx_light.onnx.GraphProto(*args, **kwargs)

A graph defines the computational logic of a model and is comprised of a parameterized list of nodes that form a directed acyclic graph based on their inputs and outputs.

onnx_light.onnx.NodeProto(*args, **kwargs)

Computation graphs are made up of a DAG of nodes, which represent what is commonly called a 'layer' or 'pipeline stage' in machine learning frameworks.

onnx_light.onnx.FunctionProto(*args, **kwargs)

A function defines a sub-operator that can be used in a graph.

onnx_light.onnx.OperatorSetIdProto(*args, ...)

Defines a unique pair domain, opset version for a set of operators.

onnx_light.onnx.AttributeProto(*args, **kwargs)

A named attribute containing either singular float, integer, string, graph, and tensor values, or repeated float, integer, string, graph, and tensor values.

onnx_light.onnx.ValueInfoProto(*args, **kwargs)

Defines information on value, including the name, the type, and the shape of the value.

Tensor and type structures#

These classes describe values, tensors, and type annotations.

onnx_light.onnx.TensorProto(*args, **kwargs)

Defines a tensor and its content.

onnx_light.onnx.SparseTensorProto(*args, ...)

A sparse tensor.

onnx_light.onnx.TensorShapeProto(*args, **kwargs)

Defines a tensor shape.

onnx_light.onnx.TypeProto(*args, **kwargs)

Defines a type, it can be a tensor type (element type and shape), a sequence of the same element type, ...

onnx_light.onnx.SequenceProto(*args, **kwargs)

Defines a dense, ordered, collection of elements that are of homogeneous types.

onnx_light.onnx.OptionalProto(*args, **kwargs)

A container that may or may not hold a value.

onnx_light.onnx.MapProto(*args, **kwargs)

Specifies an associative table, defined by keys and values.

onnx_light.onnx.TensorAnnotation(*args, **kwargs)

Defines a tensor annotation, useful for quantized tensors.

Supporting structures#

These classes cover metadata, sharding, and auxiliary entries.

onnx_light.onnx.StringStringEntryProto(...)

Defines a key value pair, both defines a string.

onnx_light.onnx.IntIntListEntryProto(*args, ...)

Defines a key value pair, key is an integer, value is a list of integers.

onnx_light.onnx.DeviceConfigurationProto(...)

Describes a multi-device configuration for a model.

onnx_light.onnx.NodeDeviceConfigurationProto(...)

Defines a multi-device configuration proto for NodeProto.

onnx_light.onnx.ShardedDimProto(*args, **kwargs)

Describes the sharding spec for a single axis of a sharded tensor.

onnx_light.onnx.SimpleShardedDimProto(*args, ...)

Indicates that N blocks are divided into M shards.

onnx_light.onnx.ShardingSpecProto(*args, ...)

Describes the sharding spec for a specific, input or output tensor of a node.
