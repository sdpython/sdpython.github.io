ReduceMin - version 1
=====================

This page documents version **1** of operator **ReduceMin**. See :doc:`ReduceMin` for the latest version (since version 20).

- **Domain**: ``ai.onnx``
- **Since version**: 1

Computes the min of the input tensor's element along the provided axes. The resulting
tensor has the same rank as the input if keepdims equals 1. If keepdims equal 0, then
the resulted tensor have the reduced dimension pruned. Input tensors of rank zero are
valid. Reduction over an empty set of values yields plus infinity (if supported by the datatype) or the maximum value of the data type otherwise.

The above behavior is similar to numpy, with the exception that numpy defaults keepdims to
False instead of True.

**Inputs**

- **data** (*T*): An input tensor.

**Outputs**

- **reduced** (*T*): Reduced output tensor.

**Attributes**

- **axes** (*int[]*): A list of integers, along which to reduce. The default is to reduce over all the dimensions of the input tensor.
- **keepdims** (*int*): Keep the reduced dimension or not, default 1 means keep reduced dimension.

**Type Constraints**

- **T**: Constrain input and output types to high-precision numeric tensors.
  Allowed types: tensor(double), tensor(float), tensor(float16), tensor(int32), tensor(int64), tensor(uint32), tensor(uint64).
