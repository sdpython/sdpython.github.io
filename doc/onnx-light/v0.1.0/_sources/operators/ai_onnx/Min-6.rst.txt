Min - version 6
===============

This page documents version **6** of operator **Min**. See :doc:`Min` for the latest version (since version 13).

- **Domain**: ``ai.onnx``
- **Since version**: 6

Element-wise min of each of the input tensors. All inputs and outputs must
have the same shape and data type.

**Inputs**

- **data_0** (*T*) (variadic): List of tensors for Min

**Outputs**

- **min** (*T*): Output tensor. Same dimension as inputs.

**Type Constraints**

- **T**: Constrain input and output types to float tensors.
  Allowed types: tensor(double), tensor(float), tensor(float16).
