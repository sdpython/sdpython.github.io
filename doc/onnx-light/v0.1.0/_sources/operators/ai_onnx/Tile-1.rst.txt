Tile - version 1
================

This page documents version **1** of operator **Tile**. See :doc:`Tile` for the latest version (since version 13).

- **Domain**: ``ai.onnx``
- **Since version**: 1

Repeat the elements of a tensor along an axis.

**Inputs**

- **input** (*T*): Input tensor of any shape.
- **tiles** (*T*): Number of repeated copies to make of the input tensor.
- **axis** (*T*): Axis along which to repeat.

**Outputs**

- **output** (*T*): Output tensor of same shape and type as input.

**Type Constraints**

- **T**: Constrain input types to float tensors.
  Allowed types: tensor(double), tensor(float), tensor(float16).
- **T1**: Constrain tiles and axis's type to int64 tensors.
  Allowed types: tensor(int64).
