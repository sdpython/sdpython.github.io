Constant - version 13
=====================

This page documents version **13** of operator **Constant**. See :doc:`Constant` for the latest version (since version 25).

- **Domain**: ``ai.onnx``
- **Since version**: 13

This operator produces a constant tensor. Exactly one of the provided attributes, either value, sparse_value,
or value_* must be specified.

**Outputs**

- **output** (*T*): Output tensor containing the same value of the provided tensor.

**Attributes**

- **sparse_value** (*sparse_tensor*): The value for the elements of the output tensor in sparse format.
- **value** (*tensor*): The value for the elements of the output tensor.
- **value_float** (*float*): The value for the sole element for the scalar, float32, output tensor.
- **value_floats** (*float[]*): The values for the elements for the 1D, float32, output tensor.
- **value_int** (*int*): The value for the sole element for the scalar, int64, output tensor.
- **value_ints** (*int[]*): The values for the elements for the 1D, int64, output tensor.
- **value_string** (*string*): The value for the sole element for the scalar, UTF-8 string, output tensor.
- **value_strings** (*string[]*): The values for the elements for the 1D, UTF-8 string, output tensor.

**Type Constraints**

- **T**: Constrain input and output types to all tensor types.
  Allowed types: tensor(bfloat16), tensor(bool), tensor(complex128), tensor(complex64), tensor(double), tensor(float), tensor(float16), tensor(int16), tensor(int32), tensor(int64), tensor(int8), tensor(string), tensor(uint16), tensor(uint32), tensor(uint64), tensor(uint8).
