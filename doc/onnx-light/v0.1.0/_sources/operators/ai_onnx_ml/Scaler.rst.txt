Scaler
======

- **Domain**: ``ai.onnx.ml``
- **Since version**: 1

Rescale input data, for example to standardize features by removing the mean and scaling to unit variance.

**Inputs**

- **X** (*T*): Data to be scaled.

**Outputs**

- **Y** (*tensor(float)*): Scaled output data.

**Attributes**

- **offset** (*float[]*): First, offset by this. Can be length of features in an [N,F] tensor or length 1, in which case it applies to all features, regardless of dimension count.
- **scale** (*float[]*): Second, multiply by this. Can be length of features in an [N,F] tensor or length 1, in which case it applies to all features, regardless of dimension count. Must be same length as 'offset'

**Type Constraints**

- **T**: The input must be a tensor of a numeric type.
  Allowed types: tensor(double), tensor(float), tensor(int32), tensor(int64).
