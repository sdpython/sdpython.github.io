Binarizer
=========

- **Domain**: ``ai.onnx.ml``
- **Since version**: 1

Maps the values of the input tensor to either 0 or 1, element-wise, based on the outcome of a comparison against a threshold value.

**Inputs**

- **X** (*T*): Data to be binarized

**Outputs**

- **Y** (*T*): Binarized output data

**Attributes**

- **threshold** (*float*): Values greater than this are mapped to 1, others to 0.

**Type Constraints**

- **T**: The input must be a tensor of a numeric type. The output will be of the same tensor type.
  Allowed types: tensor(double), tensor(float), tensor(int32), tensor(int64).
